两个版本一起传输、分别运行

A 新版：autonomous/，stock AMCL + NavFn A* + RPP。
B 简化原版：student_ws/，直接AMCL位置 + 60cm四方向A* + 匀速中心线 + IMU相对转弯；无动态障碍。
两个版本轮流启动，不能同时控制机器人。

电脑：一次传完整包
scp ~/rb3302_fresh/rb3302_versions.tar.gz ubuntu@192.168.50.7:~/

单独SSH
ssh ubuntu@192.168.50.7

机器人：解压并首次编译（新增legacy_base入口，这次需要编译）
tar -xzf ~/rb3302_versions.tar.gz -C ~
cd ~/rb3302_fresh
sha256sum -c VERSIONS.sha256 --quiet
bash ~/rb3302_fresh/prepare_robot.sh

先试B：简化原版，从X朝N，X→O→Q→X
bash ~/rb3302_fresh/run.sh X N X,O,Q,X

电脑另外一个终端：原版RViz
bash ~/rb3302_fresh/rviz.sh

结束B后再试A：先在机器人控制终端按Ctrl+C，重新摆回X朝N
bash ~/rb3302_fresh/autonomous/run.sh robot X N X,O,Q,X

电脑另外一个终端：先关旧RViz，再开新版RViz
bash ~/rb3302_fresh/autonomous/rviz.sh

以后只修改Python或参数，不用每次重新安装依赖或编译。
两个版本都需要按实际摆放填写起点和朝向。仿真验收不代表实机已验证。
