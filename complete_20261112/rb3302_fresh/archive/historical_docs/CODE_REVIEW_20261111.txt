Fixed in preceding review step

   V2 now targets the actual absolute route heading (3-degree yaw completion).
2. V2 straight motion did not enable measured angular-rate PI used by RPP.
   Straight motion now enables the same existing rate feedback.

Fixed in this review
3. The new heading alignment was called at every line action, including RPP-to-
   straight transitions. Align only on mission/goal departure or after replanning;
   continuous path sections keep moving and correcting their heading.
4. Rate PI output could exceed 2 rad/s while the active driver clips to 2 rad/s.
   Shared rate trim now respects that existing actuator-command limit and prevents
   integral accumulation further into saturation. This is a command limit, not a
   claim that the measured robot can reach 2 rad/s.
5. MapPlanner.clear_line(a,a) divided by zero. Zero-length clearance checks now
   inspect the point without dividing by zero.
6. Removed unused V2 in_curve state; did not change obstacle decisions.
