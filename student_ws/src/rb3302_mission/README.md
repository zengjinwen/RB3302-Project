# 简化原版

只运行 mission 和 legacy_base。另一版在独立 autonomous 目录。

- AMCL提供位置和朝向；底层EKF/IMU仍服务于AMCL，任务不再单独订阅IMU或融合odom。
- 58cm四方向A*，沿格子中心连线，只保存转弯点和目标。
- 直线0.10m/s，差速底盘Stanley式控制：omega=k_heading*(wrap(路线朝向-AMCL朝向)-atan2(k_cross*横向误差,v+v_soft))；用车体中心到路线的横向距离，输出角速度而非汽车转向角。删除直线PID及积分、微分状态。当前参数1.0/0.4/0.10为待实机验证起点。
- 转弯点沿来向延长10cm停车；固定相对90度，AMCL判断完成，接近目标减速。没有转弯总时限；若车卡住但定位仍有效，需Ctrl+C停车。
- 目标点沿来向走到格子中心；普通转弯点仍延长10cm；不提前进入目标格子慢速对齐，不做多帧位置复核；目标点停3秒。
- 无动态避障、旧控制器切换、转弯超时或任务退出关闭全套的联动。
- AMCL过期时发零速度等待；其他任务运行异常报告原因、发零速度并结束任务节点，不再无限等待；定位和雷达不会被联动关闭。启动参数和静态地图无路错误仍报告，不伪装为成功。

本轮仅做源码/入口一致性检查，没有重新运行仿真或实机。

转弯当前提前15度发零速度：90度在AMCL测得75度时停车；请求角度不超过15度时不单独原地转，由直线纠偏处理。实际停车角度需实机观察。

当前Stanley使用车体前方10cm参考点：e_front=e_center-0.10*sin(heading_error)。固定中心线不变，回正增益1.5、横向增益0.4、软化速度0.10，角速度上限0.50rad/s，直线速度仍0.10m/s。每个目标之间保留上一条路线朝向，所有原地转向按路线差取90度整数倍；删除AMCL重新计算任意角度的起步对准。朝向剩余误差与横向距离分别进入Stanley，不能把两者视为同一个量。新参数未实机验证。

当前直线控制改为朝向PID＋Stanley横向项：omega=1.5*heading_error+I-0.08*filtered_yaw_rate-1.5*atan2(0.4*front_cross,v+0.10)。Ki=0.03，I项贡献限于±0.05rad/s并抑制饱和积累；AMCL新消息时间用于积分和转速差分，D滤波时间0.20秒。每段开始及定位中断后重置I/D。直线速度0.10、角速度上限0.50、前方参考点0.10均保持。原地转向、15度补偿、中心线、到点零交叉判断和停3秒均未改。参数尚未实机验证。
